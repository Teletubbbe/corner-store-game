# Зафиксированные правила игрового ядра

## Цикл дня

- Утром игрок видит погоду, событие и примерное число покупателей.
- Событие всегда снабжено объяснением влияния при наведении.
- Игрок закупает товары непосредственно на полки. Остаток уже лежащего товара показан в счётчике.
- Выбор товара для пустой полки сразу покупает первую единицу. Каждый следующий клик по товару докупает ещё одну; отдельная кнопка убирает одну единицу.
- На одной полке может находиться только один вид товара; количество единиц не ограничено.
- Перед открытием можно убрать содержимое одной полки на единственное место склада или списать его без возврата денег.
- После открытия посетители заходят медленно и по одному. Каждый показанный посетитель остаётся в журнале на экране до конца дня.
- Итоги появляются только после последнего посетителя и затемняют магазин.
- Игра продолжается после седьмого дня.

## Спрос

- Корзины скрыты от игрока и меняются ежедневно.
- У каждого типа покупателей есть устойчивые предпочтения, но состав конкретной корзины вариативен.
- У покупателей нет бюджета: если товар найден, он оплачивается по фиксированной цене.
- Покупатель может купить доступную часть корзины. Ушедшим без покупки считается тот, кто не нашёл ни одного товара.
- Поток заметно колеблется из-за случайности, погоды и событий.
- Платный социологический опрос показывает любимые товары двух типов покупателей.

## Экономика

- Цены закупки и продажи фиксированы; игрок ими не управляет.
- Закупка сразу уменьшает кассу.
- Результат дня равен выручке минус ежедневные расходы.
- Остатки переходят на следующий день, стареют и портятся по окончании срока годности.
- После пяти завершённых дней в меню улучшений становится доступна шестая полка.
- С третьего дня доступен холодильник: молоко, яйца и готовая еда хранятся в нём вдвое дольше.
- С четвёртого дня доступна яркая вывеска, увеличивающая поток покупателей примерно на 25%.

## Баланс текущего прототипа

| Параметр | Значение |
| --- | ---: |
| Стартовая касса | 4 500 ₽ |
| Ежедневные расходы | 420 ₽ |
| Социологический опрос | 450 ₽ |
| Холодильник (с дня 3) | 5 200 ₽ |
| Яркая вывеска (с дня 4) | 6 000 ₽ |
| Новая полка | 7 000 ₽ |
| Базовые полки | 5 |
| Склад | 1 место |

Точные параметры товаров и предпочтений находятся в `logic.js` и проверяются автоматическими тестами.
