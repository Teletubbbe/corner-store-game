# Магазин у дома

Небольшая браузерная экономическая игра. Игрок управляет ассортиментом магазина, пытается предугадать скрытый спрос жителей района, следит за сроками годности и постепенно расширяет торговую точку.

## Как играть

1. Нажмите на свободную полку и выберите товар.
2. Укажите, сколько единиц должно лежать на полке, и оплатите закупку.
3. Ориентируйтесь на погоду, событие и ожидаемый поток покупателей.
4. Откройте магазин: посетители будут заходить по одному, а товары исчезать с полок после покупки.
5. Изучите итог дня, остатки и порчу, затем спланируйте следующую закупку.

У магазина есть один складской слот. После пяти завершённых дней открывается покупка дополнительной полки. Игра не заканчивается на седьмом дне.

## Локальный запуск

Игра не требует сборки. Откройте `index.html` или запустите любой статический веб-сервер в этой папке.

## Проверка логики

```bash
node --test logic.test.js
```

Прогресс партии сохраняется в браузере.
